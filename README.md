# 📊 BICronograma

> Plano de estudos interativo de Power BI — 4 meses, do zero ao profissional.

🔗 **[Acesse o site aqui](https://jaumsms.github.io/BICronograma/roadmap.html)**

---

## Sobre o projeto

O **BICronograma** é um site de acompanhamento de estudos desenvolvido para organizar e visualizar a jornada de aprendizado em Power BI de forma prática e motivadora.

O projeto conta com:

- **Portfólio de dashboards** com projetos de Supply Chain e Financeiro
- **Roadmap interativo** de 4 meses com 16 semanas de conteúdo estruturado
- Progresso salvo localmente por semana e por mês
- Tema claro/escuro com persistência entre páginas
- Layout responsivo para desktop e mobile

---

## Tecnologias utilizadas

- HTML5 + CSS3 (variáveis, animações, grid)
- JavaScript puro (sem frameworks)
- GitHub Pages para deploy

---

## Estrutura do roadmap

| Mês | Tema | Conteúdo |
|-----|------|----------|
| 1 | Fundamentos | Power Query, modelagem, conexões |
| 2 | DAX & Visual | DAX básico/intermediário, design de dashboards |
| 3 | Avançado | Storytelling, DAX avançado, performance |
| 4 | Profissional | Power BI Service, automação, portfólio, deploy |
